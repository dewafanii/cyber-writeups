#  Web Application Security & Penetration Testing Portfolio

This repository contains a collection of **security assessment writeups/reports** I've worked on independently, as part of my ongoing learning process and portfolio toward a career in **Web Application Security / Penetration Testing**.

The writeups here cover a variety of vulnerability types and testing scenarios — ranging from web application vulnerabilities (such as access control issues, injection flaws, etc.) to vulnerable machine/CTF walkthroughs. Each writeup is based on testing I performed myself in a lab or practice environment, focusing on how the vulnerability was found, proven, and mitigated.

All files are stored as PDFs. This folder will keep growing as I complete new assessments/labs.

---

## 📝 Report Format

For readability, each writeup generally follows this structure:

1. **Target/Scenario Description** — the application or lab being tested.
2. **Findings & Vulnerability** — the technical root cause of the issue found.
3. **Proof of Concept (PoC)** — reproduction steps with screenshots.
4. **Impact** — the potential risk if this vulnerability existed on a real system.
5. **Recommendations/Mitigation** — suggested fixes from a defensive standpoint.
